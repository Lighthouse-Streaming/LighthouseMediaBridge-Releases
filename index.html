These are free unsigned installers. macOS and Windows may show first-run safety warnings.

macOS install

  1. Download the macOS DMG.
  2. Open the DMG and drag Lighthouse Media Bridge into Applications.
  3. If macOS says the app is damaged or cannot be opened, open Terminal and run: xattr -dr com.apple.quarantine "/Applications/Lighthouse Media Bridge.app"
  4. Open Lighthouse Media Bridge from Applications.

Windows install

  1. Download the Windows installer.
  2. If Windows SmartScreen appears, choose More info.
  3. Choose Run anyway.
